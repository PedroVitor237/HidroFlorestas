# Backlog mínimo de implementação

## Convenções

- **Estado** registra a posição atual da entrega, não sua conclusão técnica.
- **Prioridade** usa `P0` para a primeira entrega, `P1` para próximos habilitadores, `P2` para o
  ciclo seguinte e `P3` para trabalho posterior.
- **Tamanho relativo** usa `P`, `M` e `G` somente para comparação de abrangência; não representa
  prazo.
