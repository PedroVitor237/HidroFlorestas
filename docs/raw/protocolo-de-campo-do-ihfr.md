# PROTOCOLO DE CAMPO DO IHFR

**Índice HidroFlorestal de Risco**

## 1. Objetivo do protocolo

Estabelecer procedimentos padronizados para coleta de dados ambientais utilizados no cálculo do Índice HidroFlorestal de Risco (IHFR), permitindo avaliar a vulnerabilidade hidroambiental de propriedades rurais.

O protocolo foi desenvolvido para aplicação em paisagens rurais do Maranhão, com foco especial na região do Baixo Itapecuru.

## 2. Escala de aplicação

O protocolo pode ser aplicado em três escalas:

| escala | aplicação |
|---|---|
| propriedade rural | diagnóstico individual |
| comunidade rural | análise territorial |
| microbacia | planejamento ambiental |

Para propriedades maiores recomenda-se dividir a área em unidades de paisagem.

## 3. Equipamentos necessários

A coleta de dados exige instrumentos simples.

| equipamento | finalidade |
|---|---|
| GPS ou celular | georreferenciamento |
| trado ou pá | observação do solo |
| infiltrômetro simples (anel de infiltração) | medir infiltração |
| fita métrica | delimitação de parcelas |
| câmera ou celular | registro fotográfico |
| planilha de campo | registro de dados |

## 4. Delimitação da área amostral

Antes da coleta é necessário delimitar a área de avaliação.

### procedimento

1. identificar limites da propriedade
2. registrar coordenadas geográficas
3. dividir a área em unidades homogêneas

Critérios para divisão:

- uso da terra
- tipo de solo
- cobertura vegetal
- relevo

Cada unidade será avaliada separadamente.

## 5. Coleta de dados hídricos

### tipo de fonte hídrica

Registrar a principal fonte de água utilizada.

| tipo | classificação |
|---|---|
| nascente | baixo risco |
| rio | baixo a moderado |
| cisterna | moderado |
| poço tubular | moderado |
| poço raso | alto risco |

### profundidade do poço

Medir profundidade aproximada.

Classificação:

| profundidade | risco |
|---|---|
| >40 m | baixo |
| 20–40 m | moderado |
| <20 m | alto |

### salinização da água

Avaliar características da água.

Indicadores:

- gosto salobro
- manchas brancas no solo
- vegetação sensível

Classificação:

| condição | risco |
|---|---|
| ausência | baixo |
| suspeita | moderado |
| confirmado | alto |

## 6. Coleta de dados do solo

### teste de infiltração

### método do anel de infiltração

1. inserir anel metálico no solo
2. adicionar volume conhecido de água
3. medir tempo de infiltração

Resultado estimado.

| infiltração | risco |
|---|---|
| >40 mm/h | baixo |
| 20–40 mm/h | moderado |
| <20 mm/h | alto |

### compactação do solo

Avaliar resistência à penetração.

Indicadores:

- dificuldade de inserir trado
- solo endurecido
- presença de crosta superficial

Classificação:

| condição | risco |
|---|---:|
| baixa | 0.2 |
| moderada | 0.6 |
| alta | 0.9 |

### erosão

Identificar processos erosivos.

Tipos:

| tipo | risco |
|---|---|
| ausência | baixo |
| erosão laminar | moderado |
| sulcos | alto |
| voçoroca | crítico |

## 7. Coleta de dados de vegetação

### cobertura vegetal

Estimar percentual de cobertura.

Método visual ou por amostragem.

| cobertura | risco |
|---|---|
| >70% | baixo |
| 40–70% | moderado |
| <40% | alto |

### fragmentação da paisagem

Avaliar continuidade da vegetação.

| condição | risco |
|---|---|
| contínua | baixo |
| fragmentada | moderado |
| muito fragmentada | alto |

### presença de mata ciliar

Avaliar proteção de cursos d'água.

| condição | risco |
|---|---|
| preservada | baixo |
| parcialmente degradada | moderado |
| ausente | alto |

## 8. Coleta de dados territoriais

### declividade

Pode ser estimada por:

- aplicativo GPS
- observação do relevo

| declividade | risco |
|---|---|
| <5% | baixo |
| 5–15% | moderado |
| >15% | alto |

### uso da terra

Registrar uso predominante.

| uso | risco |
|---|---|
| floresta | baixo |
| SAF | baixo |
| agricultura | moderado |
| pastagem | moderado |
| pastagem degradada | alto |
| solo exposto | crítico |

## 9. Registro dos dados

Todos os dados coletados devem ser registrados em planilha.

Exemplo:

| variável | valor |
|---|---|
| infiltração | 25 mm/h |
| cobertura vegetal | 35% |
| compactação | alta |
| uso da terra | pastagem |

## 10. cálculo do índice

Após coleta dos dados, as variáveis são normalizadas e integradas.

Fórmula do índice:

$$
\mathrm{IHFR} = 0.35H + 0.30S + 0.25V + 0.10T
$$

onde:

$H$ = dimensão hídrica  
$S$ = solo  
$V$ = vegetação  
$T$ = territorial

## 11. classificação do risco

| IHFR | classe |
|---|---|
| 0–0.25 | baixo |
| 0.26–0.50 | moderado |
| 0.51–0.75 | alto |
| 0.76–1.0 | crítico |

## 12. interpretação do diagnóstico

Cada classe de risco indica diferentes condições ambientais.

| classe | interpretação |
|---|---|
| baixo | paisagem funcional |
| moderado | início de degradação |
| alto | degradação significativa |
| crítico | colapso hidroecológico |

## 13. recomendações ecológicas

Com base no diagnóstico podem ser recomendadas ações como:

- recuperação de APP
- implantação de sistemas agroflorestais
- aumento da cobertura vegetal
- manejo conservacionista do solo
- recuperação de nascentes

## conclusão

O protocolo de campo do IHFR estabelece um método padronizado para coleta e análise de dados ambientais necessários à avaliação da vulnerabilidade hidroambiental de paisagens rurais. Sua aplicação permite gerar diagnósticos territoriais que orientam estratégias de restauração ecológica e manejo sustentável da água e do solo.
