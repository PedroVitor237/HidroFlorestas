# Referências visuais complementares do Figma

Este diretório reúne telas usadas como referências visuais complementares ao trabalho realizado no Figma. As imagens ajudam a comunicar possibilidades de interface e contexto, mas não são fontes de verdade, requisitos aprovados nem especificações normativas.

## Imagens

- [`entrar-ou-criar-laboratorio.jpg`](entrar-ou-criar-laboratorio.jpg): tela com as opções de entrar em um laboratório existente ou criar um laboratório.
- [`inicio-apos-acessar-laboratorio.jpg`](inicio-apos-acessar-laboratorio.jpg): visão inicial apresentada após o acesso a um laboratório.
- [`areas-monitoradas.jpg`](areas-monitoradas.jpg): listagem visual de áreas monitoradas.
- [`area-monitorada-com-formulario-de-dados-da-agua.jpg`](area-monitorada-com-formulario-de-dados-da-agua.jpg): detalhe de uma área monitorada com o formulário de dados da água aberto.
- [`cadastro-de-nova-area.jpg`](cadastro-de-nova-area.jpg): formulário visual para cadastrar uma nova área de monitoramento.

## Limites destas referências

As telas não representam todo o funcionamento da plataforma, não foram projetadas considerando responsividade e podem ser modificadas livremente. Layout, textos, seções, formulários, campos, dados solicitados, navegação, posição do mapa e formas de cadastrar informações ou áreas podem mudar conforme requisitos, decisões aprovadas e necessidades de implementação.

`PENDENCIA_DE_DECISAO` — Na tela de cadastro de uma área, ainda não foi definida a forma de informar sua localização. Entre as possibilidades estão informar coordenadas manualmente, selecionar um ponto no mapa, demarcar um polígono ou usar a localização do dispositivo. Nenhuma dessas opções constitui uma decisão aprovada. Enquanto não houver definição por autoridade superior, registra-se apenas que a solução deverá priorizar eficiência e usabilidade.
